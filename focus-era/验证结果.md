# 灵枢 v0.1 验证结果

日期：2026 年 10 月 8 日。运行环境：本机 Windows + Microsoft Edge；直接 file URL，无本地服务器。

## 已通过

- 内容结构：三棵树各 108 项，总计 324 个唯一名称、唯一标识节点；六分支 × 十八阶，每个前置可达。
- 核心逻辑：事项一次性结算，空事项/非法分钟拒绝；学习点数、前置检查、跨日专注统计；暂停不计时、续计、完整与提前结算、重载后最多结算设定时长。
- 实际 UI 流程：新建含特殊字符的任务、编辑、删除、完成领取点数，科技研究与引气入体参悟，领取成就，转职灵械师，锻造并装备竹锋短剑。
- 真实 1 分钟计时测试：暂停后时间保持不变，重载保留暂停，续计后完整完成奖励仅一次；提前结算不足一分钟不增发奖励。
- 三树交互：术法火花术学习、全部 108 项显示、搜索时空创世；科技与修仙名称、分支和作用独立显示。研究对应项目改变世界设施，境界节点改变角色境界。
- 世界与装备：自动攻击与掉落、首领解锁后可前往灵雾竹海，再返回青苔原野；装备类别筛选正常。挂机不会增加学习点数/经验。
- 手账与图鉴：学习记录、已完成事项、七日图表、成长日志、可领取/已领取成就、未发现/已发现怪兽正常显示。
- 设置与存档：名字、每日目标、静心开关完整切换；导出 JSON 后通过文件选择真实导入；坏档拒绝；重置确认可以取消。
- 多窗口：同一存档的第二窗口写入被阻止，提示另一窗口正在记录，不重复发放奖励。
- 视觉检查：1440、1024、768、375 像素宽度没有页面横向溢出；七个主要页面素材加载正常，浏览器控制台没有应用异常。小屏采用页面滚动，顶部有专注入口。
- 桌面启动：独立 Edge 应用窗口默认实际视口约 1366 × 838；初始 20 点、3 条未完成示例、0 分钟学习，主计时按钮可见，图标/程序目标存在。

运行核心检查：`node checks.cjs`。浏览器截图与临时测试存档位于 `output/playwright/`，未混入用户桌面入口的独立存档。

## 交付范围

本版采用二维像素模型；手动确认事项完成，真实学习行为依赖诚实记录。桌面版不需要后台服务，浏览器配置数据在 `.userdata`（Git 忽略），学习数据可手动导出。

## 交付限制

- 目录所属 Git 仓库未配置远程地址，不能自动推送；代码保留本地提交。
- 清理未使用下载素材的操作被自动审批策略拒绝，工具仅返回 `blocked by policy`。素材已保留，不影响运行。
