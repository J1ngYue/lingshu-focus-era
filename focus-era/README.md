# 灵枢 · 专注纪元 v0.4 — 像素远征

一款本地离线的学习挂机 RPG。打开桌面的 **灵枢 · 专注纪元**，或直接用 Edge 打开 `index.html`。无需账号、服务器和网络。

## 这一版

- 全部主场景改为真正的 Canvas 2D 像素地图与精灵，使用 0x72 的角色、怪兽待机/跑动帧，武器单独挥砍，附带命中、伤害数字、消散与金币掉落。
- 米色像素面板、装备栏、任务卷轴、像素头像和技能栏。八个地区各有本地调色地图，科技发展会增加营地设施。
- 三棵树各 108 节点，共 324 个对应像素图标。科技是文明发展，修仙是境界和剑/枪/刀意、炼体、神识，术法是六系技能。
- 成长树有本源主干、六大分支和真实进阶分叉。文明与境界主脉连续；其余分支先经过六个基础节点，再分向两条进阶路线。连线与实际学习前置一致。
- 节点可拖动、滚轮缩放、搜索/回车定位、看全图和回起点。先选节点看详情，再确认点亮。详情列出所有后继方向。
- 节点 ID、存档版本、桌面入口和学习功能沿用旧版。已点亮的节点不因新版分叉被撤销。

## 学习与成长

1. **今日事项**：创建、编辑、删除待办；完成后按预计时长获得灵感和经验，每项仅奖励一次。专注结束不会自动勾选事项。
2. **专注**：预设 25/45/60/90 分钟，或自定 1–180 分钟，关联待办。每完整分钟基础 +1 灵感、+6 经验；完整达标额外 +5 灵感。暂停不计时，提前结算保留已获得奖励。
3. **挂机**：伙伴自动打怪，只增加灵石/星屑等材料，学习点数和等级经验仍靠现实任务与专注。离线最多结算四小时，速度较慢。
4. **职业和装备**：9 个职业、12 件装备，跨科技/修仙/术法转职；8 地区、32 个怪兽条目、12 项成就和学习手账。
5. **存档**：自动保存于桌面专用 Edge 配置 `.userdata`；设置里可导出/导入 JSON。多个相同配置窗口只允许一个记录进度。

静心模式与系统“减少动态”会停止战斗动效和精灵帧动画。挂机规则继续运行。小屏幕保留任务和专注入口。

## 美术与授权

- [0x72 DungeonTileset II](https://0x72.itch.io/dungeontileset-ii)：CC0 角色/怪兽动画和武器。原包不含攻击序列，游戏用独立武器、位移与特效表现攻击。
- [Kenney Tiny Town](https://kenney.nl/assets/tiny-town)：CC0 地图；本版统一调色后生成八套本地地形。
- [Kyrise’s Free 16x16 RPG Icon Pack](https://kyrise.itch.io/kyrises-free-16x16-rpg-icon-pack)：CC BY 4.0 部分道具图标，合成节点边框和阶段标记。科技/操作符号另有原创像素图。

署名、许可链接和改动说明见 `assets/pixel/LICENSES.md`，游戏设置页也可查看。商用游戏只作设计参考，没有复制其美术。

## 验证与开发

Windows 请直接调用 Node，不用 `.cmd` 包装：

```powershell
& 'C:\Program Files\nodejs\node.exe' .\build-game.cjs
& 'C:\Program Files\nodejs\node.exe' .\checks.cjs
& 'C:\Program Files\nodejs\node.exe' .\asset-checks.cjs
& 'C:\Program Files\nodejs\node.exe' .\motion-checks.cjs
```

`build-game.cjs` 生成与核心共用时序的 `pixel-motion.js`。运行游戏不需要 npm 或 Python。`pack-pixels.py` 仅供开发时打包下载的原始素材，使用 Anaconda Python/Pillow；交付包含全部产物。旧 3D 源码和素材保留，但入口不再加载 Three.js 或 3D 模型。

代码：`engine.js` 负责计时、奖励和战斗规则；`data.js` 提供内容与前置；`tree.js` 绘制分支图谱；`pixel-scene.js` 绘制地图与精灵；`app.js` 负责界面操作。验证记录见 `验证结果.md`。
