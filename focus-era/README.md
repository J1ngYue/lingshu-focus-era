# 灵枢 · 专注纪元

一个用来督促学习、完成今日事项的本地离线挂机游戏。米色界面与温暖像素世界，无账号、无付费、无联网依赖。

## 打开

双击桌面的 **「灵枢 · 专注纪元」**。也可以直接用 Edge 打开本目录的 `index.html`。桌面入口使用独立浏览器配置目录 `.userdata`，日常请固定从同一个入口启动，避免把进度分散到不同浏览器配置中。

1. 修改或删除起始的三个示例待办，添加今天自己的事项。
2. 选择学习事项与专注时长，开始专注；暂停时间不计入奖励。
3. 完成学习后验收成果，勾选待办，领取点数与经验。
4. 在「三道成长」研究科技、参悟修行、学习术法；达到要求后转职。
5. 怪兽由角色自动战斗，使用材料在灵器工坊锻造装备，再挑战新区域。

## 三种体系各 108 项，共 324 节点

| 体系 | 六条分支，每条 18 阶 | 实际作用 |
| --- | --- | --- |
| 大世界科技 | 聚落与文明、能源与灵网、工业与造物、防卫与远征、知识与计算、空间与星际 | 发展文明，提高世界产出和角色辅助属性；具体项目解锁营火聚落、农田、工坊、知识档案馆、水轮动力站、空港、星门等设施 |
| 修仙悟道 | 境界突破、剑意、枪意、刀意、炼体、神识 | 境界独立从引气入体推进至金仙境，武器意境与体魄/神识分支独立参悟；提高角色属性和学习增益 |
| 术法技能 | 赤焰、寒霜、雷霆、青木、星辰、时空 | 108 个命名法术永久生效；每三次攻击自动轮换施法，火/雷/星强化伤害、冰/时空降低伤害、木系恢复生命 |

节点有明确前置、角色等级及灵感消耗。分支视图、全部视图和名称搜索都可用。等级来自学习经验，修仙境界由参悟对应境界节点推进。

此外包含 9 种可转职职业、8 个探索地区、24 种普通怪兽与 8 位首领、12 件四品质装备、12 项成就、怪兽图鉴、七日学习统计与专注记录。

## 点数与时间

- 初始 20 点灵感与 40 灵石仅作启程资源。
- 完成事项获得约 `预计分钟 × 0.6` 的点数（最低 5）以及经验，每项只能结算一次。
- 每个完整专注分钟获得 1 点及经验，成长加成可以提高收益；完整达标另奖励 5 点。
- 计时结束不会自动完成事项，请自己检查学习成果。
- 暂停停止计时，提前结算保留完整分钟的奖励；开始后关闭窗口最多结算当次设定时长，不会无限累计学习奖励。
- 挂机与离线探险只产出灵石/星屑，不产生学习点数或经验。离线最多 4 小时、低速结算。
- 专注时间跨午夜按本地日期切分，未完成事项自动保留。
- 可更改名字、每日目标与静心模式。多窗口使用写入租约，避免重复计时。

软件无法验证真实学习行为，计时与事项验收依赖诚实记录。

## 存档

全部进度保存在浏览器本地存储中。在「修行设置」可导出/导入 JSON 存档。清理浏览器数据或删除 `.userdata` 会移除桌面入口的存档，建议定期导出。损坏存档不会被自动覆盖；导入前检查结构与数值，替换需要在界面中确认。

## 美术素材

本版为 **2D 像素精灵与地图**。美术来自 Kenney 官方的 [Tiny Town](https://kenney.nl/assets/tiny-town)、[Tiny Dungeon](https://kenney.nl/assets/tiny-dungeon)、[Tiny Battle](https://kenney.nl/assets/tiny-battle)。三个素材包均为 CC0，许可证保留在 `assets/kenney/*/License.txt`。世界布局、系统内容、界面与标志为本项目制作。

## 验证与实现

零第三方运行依赖，HTML/CSS/JavaScript，可直接通过 `file:///` 运行。核心逻辑与界面分开，便于验证计时与奖励。运行 `node checks.cjs` 检查节点数/唯一性、全节点可达、前置关系、任务奖励一次性、暂停/续计、关闭重载、跨午夜、离线材料、转职、装备、成就及坏档拒绝。实际浏览器验收覆盖见 `QA.md` 和 `验证结果.md`。

桌面入口无需后台服务器。此目录所属 Git 仓库未配置远程地址；代码可本地提交，远程推送需配置后再执行。
