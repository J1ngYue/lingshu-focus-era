# 灵枢 · 专注纪元 v0.8.0 — 仙械山海

一款本地离线的学习挂机 RPG。打开桌面的 **灵枢 · 专注纪元**，或直接用 Edge 打开 `index.html`。无需账号、服务器和网络。

## 这一版

- 重绘三种修仙角色的九个姿态：黑发青白剑修、冰蓝剑修、紫衣符修。全新存档和无武器的旧存档均配基础青锋佩剑，不额外赠送成长属性；已有装备与学习进度保留。初始剑修按攻速近身出剑，剑柄跟随各姿态的握持位置。
- 专注打怪会掉初阶、精良、史诗、传说装备，普通怪掉落率 25%，首领必掉一件。品质分布随 Lv.1–60 连续变化：初阶 80%→20%，精良 17%→37%，史诗 2.8%→28.8%，传说 0.2%→14.2%（条件为已掉一件装备）。自动收入灵器匣，可手动换装；重复装备化为 1–4 星屑。工坊展示当前等级的真实概率，掉落时有战场浮字、品质粒子和拾取提示。暂停或纯挂机没有掉落，装备不额外赠送点数或经验。


- 横屏粗描边纸片风：仙侠角色、青蓝森林、头像战力、关卡路线、生命球、专注球和经验条。底栏改为深玉色与黄铜边框，灵器匣显示品质和装备名称，六系术印显示对应图标、解锁状态与阶数，右侧直接进入今日委托和专注。
- 八张独立地区插画，包括古风科技城、灵能都市、月宫、云海浮岛、熔炉城、太虚仙境与三界天枢城。三种角色使用独立动作姿态，并使用连续精灵网格变形表现蓄力、挥臂、迈步、受击和恢复。角色与怪物按各自攻速独立出手，不等待对方攻击或固定动画结束。攻速加成来自武器、机械造物、剑枪刀意和时空术法；动画跟随各自的攻击进度，真实命中时立即反馈伤害。实际自动施法时，对应术印会亮起。
- 基础青锋佩剑加 12 件可掉落装备，改变角色披风、肩甲、佩剑、玉佩与高阶光环；战场和头像均显示当前装备。任务与专注收进可展开、可收起的学习卷轴。
- 三棵树各 108 节点，共 324 个不同的线稿成长图标，以设施/法器/术式为主图，以含义相关的元素为附图。科技是文明发展，修仙是境界和剑/枪/刀意、炼体、神识，术法是六系技能。分支、搜索结果、前后继节点、增益、条件、状态和缩放控件也配有图标。
- 成长树有本源主干、六大分支和真实进阶分叉。文明与境界主脉连续；其余分支先经过六个基础节点，再分向两条进阶路线。连线与实际学习前置一致。
- 节点可拖动、滚轮缩放、搜索/回车定位、看全图和回起点。先选节点看详情，再确认点亮。详情列出所有后继方向。点选有图标回弹、选中环和详情渐入；前置路径有流光；确认点亮后有连线亮起、节点光环、八颗星光粒子和浮动提示。按钮有点击涟漪，资源实际变化时有数字反馈。拖动不会触发点选或学习。
- 节点 ID、存档版本、桌面入口和学习功能沿用旧版。已点亮的节点不因新版分叉被撤销。

## 学习与成长

1. **今日事项**：创建、编辑、删除待办；完成后按预计时长获得灵感和经验，每项仅奖励一次。专注结束不会自动勾选事项。
2. **专注**：预设 25/45/60/90 分钟，或自定 1–180 分钟，关联待办。每完整分钟基础 +1 灵感、+6 经验；完整达标额外 +5 灵感。暂停不计时，提前结算保留已获得奖励。
3. **奖励来源**：只有专注和完成事项获得点数、经验及材料。专注运行期间才推进战斗并掉落灵石/星屑；未专注、暂停和无专注的离线挂机均不增加奖励或击杀进度。成就仅授予印记，不额外兑换成长点数。
4. **职业和装备**：9 个职业、13 件装备，跨科技/修仙/术法转职；8 地区、32 个怪兽条目、12 项成就和学习手账。
5. **存档**：自动保存于桌面专用 Edge 配置 `.userdata`；设置里可导出/导入 JSON。多个相同配置窗口只允许一个记录进度。全新或重置存档从零经验、零货币、空节点/职业/任务/学习记录与基础青锋佩剑开始，不赠送启动资源。

静心模式与系统“减少动态”会停止战斗、界面过渡、成长树流光和点击特效。挂机规则继续运行。小屏幕保留四个主菜单、任务和专注入口。沿用浏览器自带的 Canvas、SVG、CSS 与 Web Animations，无需额外安装游戏引擎。

本版可查看 [从零开始预览](preview.png)、[剑修与掉落演示](preview-cultivator.webm)、[实时攻速对比录像](preview-speed.webm)、[324图标总览](preview-icons.png) 和 [成长树动效演示](preview-feedback.webm)。验收结果见 [验证记录](验证结果.md)。公开仓库：[J1ngYue/lingshu-focus-era](https://github.com/J1ngYue/lingshu-focus-era)。

## 美术与授权

当前美术使用内置 imagegen 生成，并保存于 `assets/ink`；完整提示词和提取说明见 [生成记录](assets/ink/生成记录.md) 与 [修仙角色 v2 提示词](assets/ink/修仙角色-v2-生成记录.md)。界面和节点图标为 SVG 线稿。下列像素素材为保留的旧版资产，当前游戏入口不加载其场景：

- [0x72 DungeonTileset II](https://0x72.itch.io/dungeontileset-ii)：CC0 角色/怪兽动画和武器。原包不含攻击序列，游戏用独立武器、位移与特效表现攻击。
- [Kenney Tiny Town](https://kenney.nl/assets/tiny-town)：CC0 地图；本版统一调色后生成八套本地地形。
- [Kyrise’s Free 16x16 RPG Icon Pack](https://kyrise.itch.io/kyrises-free-16x16-rpg-icon-pack)：CC BY 4.0 部分道具图标，合成节点边框和阶段标记。科技/操作符号另有原创像素图。

署名、许可链接和改动说明见 `assets/pixel/LICENSES.md`，游戏设置页也可查看。商用游戏只作设计参考，没有复制其美术。

## 验证与开发

Windows 请直接调用 Node，不用 `.cmd` 包装：

```powershell
& 'C:\Program Files\nodejs\node.exe' .\build-game.cjs
& 'C:\Program Files\nodejs\node.exe' .\checks.cjs
& 'C:\Program Files\nodejs\node.exe' .\asset-checks.cjs
& 'C:\Program Files\nodejs\node.exe' .\motion-checks.cjs
```

`build-game.cjs` 生成与核心共用时序的 `pixel-motion.js`。运行游戏不需要 npm 或 Python。`pack-pixels.py` 仅供开发时打包下载的原始素材，使用 Anaconda Python/Pillow；交付包含全部产物。旧 3D 源码和素材保留，但入口不再加载 Three.js 或 3D 模型。

代码：`engine.js` 负责计时、奖励和战斗规则；`data.js` 提供内容与前置；`tree.js` 绘制分支图谱；`pixel-scene.js` 绘制地图与精灵；`app.js` 负责界面操作。验证记录见 `验证结果.md`。
